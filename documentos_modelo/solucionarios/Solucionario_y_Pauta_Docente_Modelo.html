2. Justificación de Claves y Desglose de Distractores

Pregunta 1  |  Clave: C Localizar · Tarea (a)
📌 Reformulación simple: ¿Qué hecho puntual menciona el autor en el párrafo 1?
Evidencia textual: Párrafo 1, línea 3: «...los datos reflejan una variación directa...»
A (Cambio de foco): Alude a un tema secundario ajeno a la pregunta.
B (Sobregeneralización): Utiliza cuantificadores absolutos sin base textual.
D (Literalización forzada): Copia palabras textuales de una zona no pertinente.

3. Protocolo de Corrección por Tercios (Preguntas Abiertas)

Se aplica match semántico flexible: no se penaliza ortografía literal ni caligrafía si el sentido central es comprensible.

Nivel de Logro Puntaje Criterio de Evaluación y Evidencia Requerida
Logrado Completo 3 / 3 pts Identifica con precisión el elemento solicitado, fundamenta con evidencia textual y elabora un juicio valorativo o explicación completa.
Logrado Parcial 2 / 3 pts Reconoce la idea principal pero la fundamentación es incompleta o carece de cita de apoyo.
Insuficiente 1 / 3 pts Menciona un concepto aislado o rescata una frase suelta sin responder cabalmente a lo solicitado.
No Observado 0 / 3 pts Respuesta en blanco, ilegible o incongruencia total.
