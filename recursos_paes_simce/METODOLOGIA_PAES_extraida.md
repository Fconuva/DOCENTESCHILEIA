## 1. Marco DEMRE: 3 habilidades y 14 tareas lectoras

La PAES mide **solo 3 habilidades**. Cada pregunta se etiqueta con una de estas y con una "tarea lectora" (a–n). Moraleja organiza sus capítulos según esta tabla:

| Habilidad | Tarea lectora (DEMRE) | Cap. Moraleja |
|---|---|---|
| **LOCALIZAR** | a. Extraer información explícita | 2, 8 |
| | b. Identificar info. explícita por sinónimos/paráfrasis | 2 |
| **INTERPRETAR** | c. Establecer relación (problema/solución, causa/consecuencia, categoría/ejemplo) | 1, 5 |
| | d. Elaborar inferencias (significado local y global) | 4 |
| | e. Determinar el significado de una parte/párrafo/sección o del todo | 7 |
| | f. Sintetizar las ideas centrales de una sección o del texto | 3 |
| | g. Identificar la jerarquía de las ideas | 3 |
| | h. Reconocer la función de un elemento textual (ejemplos, citas, figuras) | 4, 10 |
| **EVALUAR** | i. Determinar la intención comunicativa según el destinatario | 4, 10 |
| | j. Juzgar la información (calidad, pertinencia, suficiencia, consistencia) | 8, 10 |
| | k. Juzgar la forma en relación con la información | 4 |
| | l. Calificar la posición, actitud o tono del emisor/narrador | 9 |
| | m. Valorar recursos lingüísticos y no lingüísticos (imagen, color, tipografía) | 4 |
| | n. Valorar la información textual en relación con nuevos contextos | — |

**Formato oficial vigente:** 7 textos, 65 preguntas, **4 alternativas (A–D)**, respuesta única, 2 h 30.

## 2. LOCALIZAR — Procedimiento (5 pasos)

Para preguntas que piden **información explícita** ("¿Qué se afirma…?", "Según el texto…", "¿Cuál de las siguientes es CORRECTA…?").

1. **Paso 1 — Leer el texto completo.** Da una visión global del discurso y su propósito.
2. **Paso 2 — Leer y analizar la pregunta.** Identifica los elementos relevantes: el **referente** (sobre qué se pregunta) y los verbos/marcas ("se afirma" → la información está explícita, igual o parafraseada).
3. **Paso 3 — Buscar en el texto** la información pertinente (subrayarla).
4. **Paso 4 — Contrastar** la información hallada con cada alternativa.
5. **Paso 5 — Comprobar** la respuesta.

**Distractores típicos:** una opción que **cambia un dato** del texto, una que afirma algo **que el texto no dice** (aunque sea verosímil), una que **invierte** una relación.

## 3. INTERPRETAR — Síntesis / idea principal (macrorreglas)

Para preguntas de **tema, idea principal o contenido fundamental**.

> **Regla de oro:** el tema/idea principal se ajusta a la **intención del emisor**, no a la impresión emotiva del lector.

**Las 3 macrorreglas (van Dijk)** para extraer el contenido fundamental:
- **Selección:** quedarse solo con las partes relevantes y dominantes (los conceptos clave que se reiteran).
- **Supresión:** eliminar lo no esencial (ejemplos, redundancias, detalles menores, datos circunstanciales) sin alterar el eje temático.
- **Generalización:** agrupar varias ideas/palabras afines bajo **un solo concepto** (ej.: "Francia, España, Egipto, Australia" → "distintos países").

**Fórmula:** TEMA (sujeto temático) + ideas que se reiteran → IDEA PRINCIPAL.

**Cómo descartar la alternativa errónea** (preguntas de idea principal):
- un concepto **demasiado general/amplio**;
- un concepto **demasiado específico**;
- una opción que **omite el concepto clave**.

---

## 4. INTERPRETAR — Función de un elemento y relaciones discursivas

- **Función de un elemento** (ejemplo, cita, dato, figura retórica): preguntar *¿para qué está aquí?* (ilustrar, apoyar, contrastar, anticipar…), no qué dice literalmente.
- **Relaciones discursivas** entre párrafos/segmentos: problema/solución, causa/consecuencia, categoría/ejemplo, oposición, secuencia, comparación. Nombrar **el tipo** de relación.

---

## 5. EVALUAR — Propósito / intención comunicativa

Moraleja distingue 4 procedimientos según el alcance de lo que se evalúa:

- **Propósito general del texto** ("¿con qué finalidad se escribió?"): informar/explicar, persuadir/convencer, narrar, instruir, describir.
- **Propósito de un segmento o párrafo** ("¿con qué propósito se menciona X en el párrafo N?").
- **Propósito de un recurso lingüístico** (una expresión, una cita, una pregunta retórica).
- **Propósito de un recurso del modo visual** (imagen, color, tipografía, disposición gráfica) — clave para **textos discontinuos** (infografías).

---

## 6. EVALUAR — Posición, actitud y tono del emisor

- **Calificar la postura** del emisor/narrador frente a un tema (a favor, crítica, matizada…).
- **Tono/actitud:** irónico, admirativo, crítico, neutral, nostálgico, etc. — siempre **justificado con marcas del texto**.
- **Juzgar la información:** ¿es consistente? ¿la conclusión dice más de lo que sus datos permiten? ¿usa lenguaje prudente ("sugieren", "probablemente") o categórico?

---

## 7. Reglas de construcción de ítems (anti-adivinación)

Aplicadas en nuestras guías y coherentes con la PAES oficial:
- **4 alternativas (A–D)**, una sola correcta.
- **Extensión pareja**: la correcta NUNCA debe ser la más larga.
- Distractores **plausibles**, cada uno con un tipo de error reconocible: generaliza / sobreinterpreta / literaliza / contradice / cambia el foco.
- Cada ítem etiquetado con **habilidad + tarea lectora**.
- El feedback explica **por qué** la correcta lo es y **por qué fallan** las otras (estilo solucionario Moraleja).

## 8. Estructura de LECCIÓN COMPLETA (estándar obligatorio — anatomía Moraleja)

Moraleja NO es solo práctica: su 7ª edición lo enuncia textual —cada lección trae *"una definición de la habilidad, un procedimiento, un modelado y una amplia [ejercitación]… preguntas (Nivel 1, Nivel 2, Nivel 3)"* y busca *"aprender del error con estrategias metacognitivas"*. Toda guía nuestra debe seguir esa secuencia:

1. **EXPLICA** — definición de la habilidad + **procedimiento** (estrategia paso a paso). Breve y visual.
2. **MODELA** — ejemplo resuelto (caja **"ATENCIÓN"**): muestra el razonamiento, no solo la respuesta.
3. **EJERCITA GRADUADO** — preguntas etiquetadas por **Nivel 1 / 2 / 3** (de fácil a difícil; andamiaje que se retira). Cada ítem con habilidad + tarea DEMRE.
4. **EVALÚA** — al cierre, **logro por habilidad** (Localizar/Interpretar/Evaluar), no solo el puntaje total.
5. **ANALIZA EL ERROR** — feedback explicativo por ítem + **diagnóstico**: señalar la habilidad más débil y a qué volver.

Por cada texto: **encuadre breve del género** y su propósito → texto con fuente (propio/adaptado, 500–2000 palabras) → 5–7 preguntas. Contextos de lectura (Puntaje Nacional): **Leo para aprender** / **Leo para mí** / **Leo para vivir en comunidad** (este último con **textos discontinuos**).
