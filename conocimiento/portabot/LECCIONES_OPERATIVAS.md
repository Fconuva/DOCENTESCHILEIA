# Lecciones operativas de Portabot

Transferencia despersonalizada del índice canónico revisado el 7-oct-2026.
Los procedimientos detallados viven en la [skill de portafolio](../../.agents/skills/portafolio-docente/SKILL.md).
Estas lecciones no importan datos, permisos ni preferencias individuales.

## Identidad, fuentes y alcance

| Fallo que hay que evitar | Acción y evidencia que lo previenen |
|---|---|
| Apellido parecido asignado a una carpeta | Confirmar identidad técnica y vínculo de carpeta; dos candidatos quedan sin emparejar. |
| Inscripción vieja contradice último cambio | Leer decisión contemporánea y material actual; conservar fuente/fecha. |
| Volcado local tomado como estado vivo | Leer el origen autorizado y fechar la lectura; el volcado se trata como foto. |
| Modalidad deducida por profesión | Confirmar agrupación y variante; abrir su manual y rúbrica. |
| ECEP usado para elegir Portafolio | Separar instrumentos y fuentes, con proceso y asignatura propios. |
| M2 reabre M1 ya entregado | Mantener módulo y alcance; propagación solo a dependencias autorizadas. |
| Falta un dato que el docente ya dio | Buscar registro, módulo/cuestionario, chat, adjuntos y control antes de pedirlo. |
| Archivo adjunto no descargable declarado vacío | Informar no comprobado; no inventar contenido ni diagnóstico. |
| API de comentarios vacía borra observaciones | Revisar comentarios embebidos en Word/PowerPoint. |
| Plantilla reemplaza requisito oficial | Citar manual, tarea, página y condición completa. |
| Regla antigua copiada a otro caso | Consultar fuente canónica vigente y separar preferencia de requisito. |

## Contenido pedagógico y evidencias

| Fallo | Control útil |
|---|---|
| Objetivo coincide por palabras, actividad no lo aborda | Revisar acción cognitiva, contenido y evidencia por experiencia. |
| Instrumento mide obediencia en vez de habilidad | Comprobar respuesta observable y criterio del objetivo. |
| Objetivo sobrecargado se arregla bajando habilidad | Corregir tarea o distribución preservando lo acordado. |
| Propuesta conjugada a pasado parece aplicación | Mantener rótulo de propuesta y separar hechos con fuente. |
| Modelo completo acredita resultados inexistentes | Aviso de simulación junto al uso y en todos los derivados. |
| Fechas tomadas del archivo | Usar fecha real declarada; en preparación no inventarla. |
| Ficha posterior a grabación llena antes | Exigir fuente posterior y conservar campos no acreditados con su estado. |
| Letra de campo usada como significado universal | Reconocer enunciado y propósito según modalidad. |
| Se eliminan causas contextuales por filtro léxico | Contrastar descriptor y explicar incidencia, sin atribuir culpa. |
| M3 necesita conflicto o firma inventados | Mantener lo que exige su manual, sin requisitos supuestos. |
| Teoría del agente se vuelve causa de decisión conjunta | Separarla como propuesta si no está en la fuente del diálogo. |
| Reflexión individual clonada entre coautores | Redactar aprendizaje y repercusión propios; coautoría no los vuelve comunes. |
| Clase depende de proyector supuesto | Confirmar sala y preparar alternativa realista. |
| Libreto es una lista inejecutable | Consigna literal, primera acción, producto, monitoreo y transiciones. |
| Suma de minutos tomada como prueba de uso | Incluir lectura, reparto, organización, respuestas y devolución. |
| Ejemplo entrega solución antes de evaluar | Separar modelado de ítem/instrumento y preservar propósito. |

## Campos, formatos y recursos

| Fallo | Control útil |
|---|---|
| Fuente corregida pero Word/PDF antiguos | Comprobar y actualizar derivados afectados; abrirlos. |
| Texto perdido detectado solo al concatenar todo | Comparar por bloque/campo y mantener cobertura. |
| Un año se convierte en lista «1.» | Preservar número original y revisar continuidad de listas en derivados. |
| Aviso solo en archivo de lectura | Llevarlo al formato copiable y mantener orden/finalidad. |
| Campo no pegable ofrece botón de copiar | Bloquear esa acción y mostrar estado, sin ocultar el borrador. |
| Aviso de completar persiste sobre dato ya declarado | Diferenciar andamio de campo vacío de advertencia de validación aún pertinente. |
| Insignia de caracteres mide versión anterior | Calcular sobre el cuerpo realmente disponible para copiar. |
| Campo no encontrado se reporta vacío | Estados distintos: presente vacío, ausente, no interpretado y no legible. |
| Recurso citado existe con otro nombre o incompleto | Abrir, comprobar correspondencia y contenido, no solo presencia. |
| Falta un adjunto pero no hay marcador pendiente | Auditar desde lista de requisitos del manual, no desde archivos existentes. |
| Editable es una imagen plana | Probar una edición concreta del uso prometido. |
| Biblioteca abre PPTX que la aplicación no abre | Validar en aplicación de uso y conservar paquete OOXML. |
| Imagen ilegible o cantidad incorrecta | Revisar a tamaño final y contar elementos útiles. |
| Guía de estudiantes lleva pauta docente | Separar destinatarios y revisar respuestas/pistas antes de publicar. |
| PDF se fuerza reduciendo letra/escritura | Redistribuir páginas; medir legibilidad y espacio físico. |

## Auditoría, simulación y concurrencia

| Fallo | Control útil |
|---|---|
| Silencio del auditor se interpreta como APTO | Declarar cobertura, límites y estado no comprobado; fallar al no leer. |
| Universo vacío termina con «0 errores» | Exigir piso de cobertura y declarar número de elementos/casos. |
| Selector no coincide con nada y parece éxito | Terminar indicando selector vacío, no publicación hecha. |
| Corrector imprime «vaciado» sin cambiar | Contar cambios reales y comprobar derivados posteriores. |
| Simulación escribe producción | Ejecutar sobre copia aislada y comprobar que origen no cambió. |
| Hash sin bytes se llama respaldo | Guardar contenido recuperable y probar identidad/restauración. |
| Autotest no informa casos ejecutados | Declarar conteo; cero casos no demuestra comportamiento. |
| Hallazgo masivo aceptado sin revisar detector | Abrir casos reales y falsos; medir límites de la herramienta. |
| Revisor es el autor con otro alias | Independencia real por actuaciones y responsables distintos. |
| APTO general omite indicadores | Evidencia y nivel por indicador/variante aplicable. |
| Dictamen favorable ignora un CORREGIR vigente | Mantener bloqueo hasta cerrar el hallazgo y revisar nueva versión. |
| APTO de otra versión o clave de módulo | Normalizar identidad de encargo, módulo, carpeta y versión/hash. |
| Detector de privacidad con verde se considera garantía | Revisar contenido y metadatos; los detectores solo cubren patrones. |
| Hook existe pero clon nuevo no lo ejecuta | Verificar instalación efectiva y agregar CI para controles compartidos. |
| Staging de carpeta arrastra trabajo ajeno | Rutas explícitas, status y diff por archivo; checkout aislado si hace falta. |
| Respaldo genérico pisa otro trabajo | Ruta única del encargo y fecha; comprobar existencia antes de copiar. |
| LF/CRLF produce falsa diferencia | Separar identidad de bytes de comparación de contenido normalizada. |

## Publicación, acuerdos y comunicación

| Fallo | Control útil |
|---|---|
| Se sube sobre carpeta de otra persona | Verificar identidad del destino, cadena de carpetas y alcance. |
| Reescritura pisa edición docente | Leer y descargar versión actual; integrar su cambio antes de publicar. |
| Limpieza de un módulo elimina otro | Respetar módulo, editor y autorización de borrado; no limpieza implícita. |
| Publicación local se anuncia como remota | Abrir versión remota y distinguir estados. |
| Enlace enviado sin probar | Comprobar destino y recurso que abrirá la persona. |
| Aviso sin control del archivo que cambió | Revisar versión actual, indicadores y hallazgos antes del anuncio. |
| Promesa futura desaparece en el chat | Registrar compromiso y responsable; deuda abierta no es listo. |
| Respuesta pisa la última del responsable | Leer salidas actuales de todos los canales pertinentes. |
| Dos hilos crean falsa ausencia de aviso | Reconciliar identidad y los hilos vinculados, no solo un JID. |
| Pregunta se trata como agradecimiento | Revisar pedido completo y pendientes antes de reaccionar. |
| Archivo/pago repetido por otro agente | Deduplicar por identidad de evento/operación y estado canónico. |
| Proyección se convierte en deuda | Separar acuerdo, precio, abono, saldo y proyección con fuente. |
| Calificación o simulación vendida como garantía | Explicar evidencia, revisión humana y límites. |
| Docente no sabe qué hacer con el archivo | Aviso autorizado con enlace y acción concreta; cierre útil. |
